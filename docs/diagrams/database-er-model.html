UniClipboardEngine 数据库关系图

依据当前迁移文件和最终结构生成。覆盖 32 张物理表：29 张当前表，以及 3 张只用于旧数据迁移的保留表。细图保留主键、关联字段和关键状态字段，完整字段仍以迁移文件为准。

总览剪贴板内容接收与传输搜索索引设备与安全

01 · Overview

六个数据区域

剪贴板条目是内容主线；接收和传输围绕条目追加。搜索是可重建数据。设备关系和空间安全状态独立保存，敏感载荷集中在密文列中。

32 张物理表

从空数据库完整执行迁移后得到的实际数量。

9 条强制外键关系

数据库直接约束内容、条目、表现形式和文件清单。

3 张迁移保留表

当前代码不再读取，只作为旧关系数据的迁移来源。

02 · Primary Data

剪贴板内容

一次捕获形成事件；事件拥有一种或多种表现形式，并对应一个历史条目。条目再保存选中表现、文件清单和当前激活状态。

03 · Workflow

接收与文件传输

这些表记录投递、接收尝试、文件传输事件和目录发布状态。它们共享条目或尝试标识，但没有数据库外键，以便保留历史并支持分阶段落地。

04 · Derived Data

搜索索引

四张表都按资料空间隔离，可以从剪贴板历史重建。词项以不可逆标签保存，供查询使用的展示内容集中在密文字段中。

05 · Local State

设备、关系与安全状态

关系、空间密钥、成员收敛和旧升级流程分别保存。它们主要通过处理后的空间或设备标识相连，敏感记录集中在密文载荷中。底部三张虚线表只为迁移旧数据保留。
