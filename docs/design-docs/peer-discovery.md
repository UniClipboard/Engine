# 设备发现与候选目录

## 边界与身份

发现回答“当前有哪些地址线索”，连接和授权回答“能否建立及使用连接”。Application 的 discovery 模块拥有观察合并、来源失效、按需查询和候选目录；Infra 将已有服务适配为 provider，并将目录输出转换到 iroh 地址查找契约。设备级网络节点拥有发现任务，Space 会话不拥有它。

目录的 `DiscoveryPeerId` 包含后端标识与不透明传输身份，不是逻辑 `DeviceId`。允许保留尚未绑定的陌生设备观察，但不自动拨号、建立配对或授予成员资格。本切片没有增加 Engine 的附近设备列表。逻辑设备与传输公钥的映射仍来自现有成员身份负责人；连接后密码身份验证、当前成员授权和 session generation 围栏继续生效。切换 Space 不缓存旧 DeviceId 绑定，也不清空仍有效的网络线索。

## 来源与有效期

- mDNS 复用节点已有 `_irohv1._udp.local` 服务与线格式。持续订阅包括主动 resolve 的设备，晚订阅获得当前快照，地址变化替换该来源的旧观察。
- 该服务是通用 iroh 服务；陌生观察只能说明发现了一个传输端点，不能据此确认它运行 UniClipboard。未来附近设备列表须另行验证产品能力，不能把未经识别的候选展示为已确认设备。
- CloudDiscoveryProvider 适配已有 DNS/PKARR 地址解析；PKARR 发布仍由同一个 endpoint 持有。查询只在连接需要地址时发生，不新增周期轮询。邀请码 rendezvous 不属于本目录。
- 一份观察包含一个后端不透明 locator，locator 可编码该来源的多条地址。来源不同的观察独立保存，不能以 mDNS 更新覆盖 Cloud，不能以 Lost 删除整个 peer。
- 原服务没有向适配层暴露可直接采用的 TTL；目录副本采用 60 秒上限。mDNS 的原观察时间保留在 `Item.last_updated`，读取缓存只交付剩余有效期，不重新续期；时间不明或过期的 mDNS 观察不进入目录。Cloud 沿用原 DNS resolver 的缓存语义，并为返回结果设置 60 秒目录副本期限。mDNS 的 Expired 提前删除来源。查询和每 5 秒维护都清理过期项，停止的订阅清除该来源；广播不再刷新或订阅掉包时，副本也不会永久有效。
- 容量按来源独立限制为 1024 份观察；新观察达到容量时淘汰该来源最早观察，不淘汰其他来源。身份最多 512 字节、locator 最多 16 KiB。所有候选只存内存，默认 Debug 隐藏身份与地址材料。

## 连接与失败责任

iroh 的生产 address lookup 消费 DiscoveryManager 输出。缓存候选先交付，provider 查询并行轮询，云端失败或缓慢不能阻塞有效本地候选。按需查询异常保留 source chain，不删除此前仍在有效期内的来源事实；没有查到新地址不能解释为设备已离线。

目录候选不改变 iroh 内部路径选择、QUIC、Relay、地址过滤或 LAN-only 设置。LAN-only 根本不装配云端解析与发布。现有传输协议和业务重试负责人保持唯一，不增加应用层的 LAN/Internet/Relay transport。

查询取消通过丢弃流完成，不创建分离查询任务。正常节点关闭先关闭目录，禁止迟到结果重新填充，再取消并等待发现任务；未完整构建的节点由任务 guard 取消。进程重启重新发现，不新增持久化格式或恢复资料。

## 验证边界

纯目录与测试provider证明多来源／期限／取消契约，真实mDNS adapter测试证明订阅和地址变更，目录lookup的真实QUIC测试证明连接桥与双向多流。

独立进程的云故障产品验收由[发现网络脚本](../../scripts/testing/run-discovery-connectivity.sh)执行：Cloud保持开启，两端完全退出并更换双栈端口；防火墙持续阻断旧端口且namespace没有公网路由。先阻断mDNS，要求实际Cloud失败终态、无成功路径和内容；再只放行mDNS，要求实际本地候选、Direct连接及合成剪贴板宿主准确读回。该对照排除持久旧地址和已有连接作为成功路径，不要求删除既有身份映射，也不新增测试专用Engine查询。

该场景复用既有合成剪贴板宿主，证明完整Engine到宿主写入口及准确读回；本地独立进程证明不代表原生桌面剪贴板、物理设备、多网段或全部平台网络栈验收。当前执行状态见[后续计划](../exec-plans/completed/2026-10-30-issue-34-followups.md)，原切片实施历史见[第一个切片计划](../exec-plans/completed/2026-10-11-peer-discovery-slice.md)。
