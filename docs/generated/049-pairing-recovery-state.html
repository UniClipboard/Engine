03 / STATE / JOINER RECOVERY

失败、断线与重启后往哪里走

只画 Joiner 的关键边界。重启通常是恢复已保存阶段，不是自动回到起点；异常出口受阶段与证据约束。

当前协议

`PendingSettlement` 重发同一 `CompleteAck`，取得并保存 `Settled` 才完成；`RecoveryRequired` 不凭超时猜测已提交或释放安全围栏。Sponsor 的 `Applied → Completed` 是独立状态机。

049 目标

不重写准入阶段；成员事实改由 Owner 接收输入。成员提交后的效果及待办在重启时从已保存状态恢复，Worker 只执行并交回结果。

来源：docs/design-docs/pairing-lifecycle.md、ADR-027、计划 049。异常出口是规则说明，不代表图中每个阶段都有同一种取消或超时转换。
