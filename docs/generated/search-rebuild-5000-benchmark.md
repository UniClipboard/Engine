# 5000 条搜索重建性能对照

日期：2026-09-10。数据来源：[真实 V3 重建测试](../../crates/uc-infra/src/search/sqlite_v3_tests.rs) 中的 `rebuild_5000_benchmark`。本文件记录本次输出，后续复测应以新输出为准。

## 环境与范围

- Apple M4，macOS 27.0；Rust 1.95.0，仓库默认 test profile（非 release）。
- 优化前基于 `8fa835f1`，仅加入相同的测速测试；优化后为本次工作区的暂存写入事务与条目定位索引改动。两边依次运行，各三轮，无并行 Cargo 验证。
- 每轮新建真实 SQLite 文件，使用仓库连接池默认设置、真实 V3 加密与搜索组件，不接触用户资料。
- 固定 5000 条中英文文本，每条含独立编号及 50 种项目编号，生成 328000 条搜索词项。输入内容与计时范围在前后保持一致。
- `build_ms` 包含固定文本生成、提取、分词和词项保护；`rebuild_ms` 包含渲染字段加密、暂存写入、整体切换、进度传递与暂存清理。
- 不包含数据库初始化、历史记录读取与解密、启动资料升级、一次性数据库整理及结果查询验证。不是 Windows 实机、用户原始资料或图片/文件混合数据的完整启动耗时。

## 逐轮结果

单位：毫秒。

| 版本 | 轮次 | 数据生成 | 重建 | 合计 |
| --- | --- | --- | --- | --- |
| 优化前 | 1 | 1775.157 | 124833.369 | 126608.526 |
| 优化前 | 2 | 1823.140 | 138819.890 | 140643.031 |
| 优化前 | 3 | 1806.117 | 131789.712 | 133595.830 |
| 优化后 | 1 | 1839.272 | 12688.800 | 14528.072 |
| 优化后 | 2 | 1832.903 | 11273.493 | 13106.396 |
| 优化后 | 3 | 1881.559 | 11467.866 | 13349.425 |

重建中位数从 131789.712 ms 降至 11467.866 ms，约提速 11.49 倍，耗时减少 91.30%。包含数据生成的合计中位数从 133595.830 ms 降至 13349.425 ms，约提速 10.01 倍。三轮不足以代表尾延迟分布，也不能据此承诺其他设备同样耗时。

## 正确性与失败验证

- 六轮均验证搜索结果总数为 5000，分页后条目无重复、无遗漏，预览能解密并匹配预期前缀。
- 六轮均验证持久词项数为 328000、完成进度为 5000、索引可用且版本一致。
- 单条暂存失败回滚测试在优化前失败（留下 1 条部分文档），优化后通过。
- 搜索相关 27 项普通测试通过，覆盖密文保存、失败重试、重建期间更新和删除、最终替换及新旧保护格式。测速测试单独执行通过；既有查询性能测试跳过。
- Windows 实机和用户原始资料验证：跳过。

## 复测

从仓库根目录运行：

```bash
cargo test -p uc-infra --lib rebuild_5000_benchmark --locked -- --ignored --nocapture
```

命令每次运行三轮并输出 JSON 计时行，测试结束自动删除生成的临时数据库。Cargo 继续复用仓库 `target`，不另建编译目录。对照时使用相同测试、相同 profile 和同一台机器；先测优化前实现，再测优化后实现，不把编译耗时或结果验证耗时计入重建。
