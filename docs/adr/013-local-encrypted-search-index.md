# ADR-013：本地历史搜索采用加密索引，而非远程可搜索加密

## 状态

已采纳。原始设计材料未记录最初决定日期。

## 背景

历史搜索只面向本机。查询发生时，内容已在解锁会话中可用，系统也没有服务端搜索执行者。

## 考虑过的方案

### 远程可搜索加密

它会增加远程查询、额外密钥管理和服务端执行面，但不能解决本机搜索的实际需求。

### 本地加密索引

索引和查询都保留在本机，可沿用现有的解锁和内容保护边界。

## 决策

搜索采用本地独立索引。索引词不以明文持久化；搜索使用从已解锁主密钥派生的专用搜索密钥。现有内容的加密存储格式保持不变。

## 理由

这个选择满足本地搜索需求，同时避免引入没有实际使用方的远程执行能力。搜索密钥与内容保护用途分离，锁定状态无法查询。

## 后果

- 搜索不依赖网络或服务端。
- 索引需要随新增、删除和重建保持一致。
- 本地访问模式、索引规模和查询频率不在本次保护范围内。
