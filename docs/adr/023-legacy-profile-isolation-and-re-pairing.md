# ADR-023：旧资料独立化与重新配对

## 决定

从 `0.20.0` 之前版本升级的已完成资料，不尝试恢复旧设备关系。设备解锁后在启动普通同步前完成一次本地独立化：保留本机历史、已完成文件、设置、设备身份和解锁材料；立即清除旧成员、可信关系、地址、邀请、旧安全记录和旧同步状态；建立只含本机的新空间，并保存“需要重新配对”标记。

## 后果

旧设备不会再被等待、探测或自动重新加入。独立化完成后 Engine 发出 `re_pairing_required` 事件，并携带 `all_devices`，表示此前的全部设备关系均已失效。产品订阅事件后立即提示用户：一台设备创建邀请码，另一台设备通过切换或加入进入该空间。为避免启动时错过事件，产品仍读取已保存标记恢复提示。新的成功加入会清除该提示。

## 不做的事

不与旧设备通信，不保留旧成员关系直到新配对成功，不增加多阶段迁移框架，也不把清理顺序交给产品端。
