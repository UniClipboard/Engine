# 前端与宿主边界

本仓库不拥有产品前端、页面状态或交互文案。桌面、iOS、Android 和 HarmonyOS 产品通过
`uc-engine` 的稳定操作、结果、事件和宿主能力接入，不能依赖内部 crate 或内部源码路径。

宿主可以负责：

- 私有目录、安全存储、系统剪贴板、文件句柄和生命周期桥接；
- 将稳定 Engine 状态转换成平台 UI；
- 根据用户明确选择启用 LAN 兼容线。

宿主不能负责：

- 复制成员、准入、加密、重试或恢复业务流程；
- 从本地缓存拼装第二份成员状态；
- 因 P2P 失败自动回退 LAN；
- 记录或展示内部错误文本中的敏感数据。

## 配对状态接入

状态语义以 [ADR-026](design-docs/decisions/026-bounded-admission-lifecycle.md) 为准；这里仅规定产品接入责任。
产品收到刷新提醒后重新读取完整设备结果，不按旧的成员版本去重，也不根据断线时长自行推断配对是否完成。
设备结果中的配对确认状态按以下文案展示：

| Engine 状态 | 产品文案 | 产品动作 |
| --- | --- | --- |
| `AwaitingPeerConfirmation` | 已完成配对，等待对方确认 | 保持关系并等待刷新 |
| `Unconfirmed` | 已完成配对，但未被确认 | 保持关系，允许用户通过既有移除成员操作删除 |
| `Confirmed` | 已完成配对 | 正常展示 |

状态为空表示没有可验证的新配对记录，不能猜成任一状态。应用重启或提醒丢失后必须重新查询；迟到确认可以把
“未被确认”补齐为完成，但已经移除的成员不能恢复。取消加入返回明确的已终止状态时，产品应结束本次配对页，
不能继续显示进行中。桌面、iOS、Android 和 HarmonyOS 各自仍需验证文案、重启重查、迟到确认和手动移除。

接口细节见 [uc-engine 跨平台核心接口](design-docs/uc-engine-interface.md)，产品语义见
[产品规格](product-specs/)，安全边界见 [SECURITY](SECURITY.md)。
