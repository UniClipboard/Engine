# PRD-001：本地加密历史搜索

## 状态

草案。

## 背景

用户需要在本机历史中快速找到已复制的内容，同时不能让搜索能力扩大内容的暴露范围。

## 目标

- 提供只在本机运行的历史搜索。
- 只在加密会话已解锁时提供搜索结果。
- 支持文本、HTML、URL 及文件相关的可提取文本。

## 需求

- 支持精确词匹配，以及单一逻辑关系的 `AND` 或 `OR` 查询。
- 支持时间范围、内容类别和文件扩展名的组合筛选。
- 删除历史时同步移除对应搜索记录。
- 支持在解锁状态下重建全部搜索记录。
- 查询语句混用 `AND` 和 `OR`、包含括号或否定时，明确提示无效，不猜测用户意图。

## 非目标

- 远程搜索或服务端搜索。
- 模糊匹配、语义搜索、短语搜索和嵌套逻辑表达式。
- 锁定状态下的受限搜索。

## 约束

- 锁定时不采集新的剪贴板内容，因此不需要补建锁定期间产生的内容。
- 搜索过程中不得把搜索词或内容正文以明文写入本地持久化位置。

## 验收标准

- 解锁后，用户能按词、时间、内容类别和扩展名检索本机历史。
- 锁定后，任何搜索请求都不返回历史内容。
- 删除一条历史后，它不会再出现在搜索结果中。
- 重建完成后，已有可搜索历史仍可被检索。
- 不支持的查询写法会返回明确的无效结果，而不是产生猜测性匹配。
