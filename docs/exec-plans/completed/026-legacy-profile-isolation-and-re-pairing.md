# Spec-026：旧资料独立化与重新配对

## 目标

让 `0.20.0` 之前的已完成资料升级后立即成为独立空间，避免任何旧成员历史继续影响新的配对。

## 唯一入口

Engine 在旧资料成功解锁后、恢复普通活动前执行一次本地处理。调用方不传递步骤，也不负责重试。

## 执行结果

1. 保留本地历史、已完成文件、设置、设备身份和解锁材料。
2. 立即删除旧成员、可信设备、设备地址、邀请和旧同步关系。
3. 删除旧空间的安全与恢复资料。
4. 使用同一份本地解锁材料建立新的单设备空间，并只保存本机成员。
5. 在任何清理前持久化“独立化进行中”和唯一目标空间；中断重试必须复用该目标，不得再次生成空间。
6. 完成空间采用、旧关系清理、安全状态清理和本机成员重建后，保存 `re_pairing_required = true`，再清除进行中记录。只有全部清理完成后才可进入待重新配对状态。

## 产品约定

独立化完成后，Engine 事件流发出 `re_pairing_required`，参数 `scope = all_devices` 表示所有旧设备关系均须重新建立。产品订阅事件后立即提示重新配对：一台设备创建邀请码，另一台设备使用切换或加入。产品启动时仍读取该标记，避免漏掉已发出的事件。成功加入新空间时标记改为 `false`。

## 失败和重启

完成标记写入前进程退出时，下次成功解锁重复同一份本地清理；不连接旧设备，不恢复旧关系。任何本地失败都阻止普通同步恢复。
