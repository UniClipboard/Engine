# 准入恢复期间的本机可用性

状态：已完成本机验收。

## 完整责任

完整负责人仍为 `SpaceAdmissionProtocol`。调用方只调用加入、查询、取消或恢复，不编排协议阶段。
本机查询和用户动作不能等待离线网络。恢复中的旧应答通过既有条件原子提交校验，不得覆盖取消、替换或激活后的状态。
重试及重启由既有 `SpaceMembershipRuntime` 触发，恢复服务保证同一实例最多一次恢复执行，保持一次性邀请码语义。
