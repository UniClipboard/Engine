# 设备组选择展示资料补全

## 交付范围

在既有 `QueryDeviceGroupChoices` 上补齐候选成员及名称、选择后的预期同步范围、暂停、待确认、
重新加入及本机结果，以及语言无关的已验证原因事实。产品桥接和生成类型同步保留资料。
本次不修改产品布局、不编写翻译、不改变实际成员授权和恢复协议。

## 表达约束

| 原因类别 | 可以表达的事实 |
| --- | --- |
| pending_removal | 某设备发起移除，等待本机决定 |
| different_removals | 两侧移除了不同设备 |
| removal_decision_disagreement | 对同一次移除存在已验证的拒绝决定与已应用分支 |
| diverged_history | 已验证的成员变化不同，不能进一步猜原因 |
| unknown | 旧资料不足，无法解释原因 |

变化携带作者、目标、所在候选侧；决定携带签名者、目标和接受/拒绝。
设备名称来自已验证准入资料，不翻译、不保证是最新名称。产品按类别翻译完整句子，不能把网络断线
推断成分歧原因，也不应仅凭时间或在线状态推荐某一组。

候选范围不代表即刻可同步；远端候选全部等待恢复确认。名单不完整、原因详情不完整和没有资料
是独立状态，不能用空名单替代未知。成员激活不表示在线。原有选择编号、revision 和本机移除确认保持不变。

## 责任与存储

唯一事实和流程责任见[成员历史职责](../../design-docs/membership-history-ownership.md#候选展示资料)，
公开结果见[Engine 接口](../../design-docs/uc-engine-interface.md)。展示快照和冲突在同一次条件提交中保存，
整份账本继续 AEAD 加密。V3 显式迁移 V1/V2，旧冲突资料保持未知，后续合法证据可补齐但不重开已完成选择。
错误证据不入库，设备身份和名称不增加到公开结果的 Debug。
