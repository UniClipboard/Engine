# 后台暂停安全

状态：已修复已复现的租约与取消完成缺口，完整后台安全验收尚未完成。

后续实施以[统一暂停、恢复与中断恢复规格](2026-09-12-unified-runtime-lifecycle.md)为准；本文件保留已完成局部修复与验证证据。

## 完整责任

Engine 生命周期负责人统一拥有暂停、恢复和最终关闭。宿主只调用暂停或恢复，不维护内部资源清理列表。
暂停成功必须意味着停止接受工作、旧工作退出且交接所需文件锁已释放；恢复重新读取持久状态后才接受工作。
失败不能发布暂停成功；重试与恢复由同一生命周期负责人串行处理。最终关闭不可恢复，暂停必须可恢复。

## 最小切片与后续范围

1. 真实 Engine 创建 Space、保存内容、暂停后由独立文件描述符验证锁释放，恢复后验证内容读取与再次暂停。
2. 检查旧操作、后台自动重建、取消与停止超时，禁止暂停后重新占用资源。
3. 核对所有停止工作的共同预算和平台绑定等待语义，不能用停止等待代替完成收尾。
4. 执行相关回归、workspace 检查、格式及架构检查。

## 已有证据

- 交接程序在本机重复得到暂停后锁不可获取、最终关闭后可获取，退出码 101。
- 当前提交与交接源码检查提交一致；该独立程序链接的是已有产物，尚不能代替当前源码重新构建验证。
- 暂停仅停止 session，最终关闭另行永久关闭安全状态；操作等待两次超时后仍返回成功。
- 自动网络恢复有独立生命周期，需继续核查暂停期间的重建入口。

## 已实现

- SessionSupervisor 持有暂停边界，暂停后拒绝网络重建，停止 session 后交接安全资源。
- Clipboard 进程级 blob 物化与 spool 清理共用活动许可；暂停等待当前完整磁盘动作退出，阻止排队动作继续，恢复保留原队列。
- Vault 等待当前读写完成后撤销复用与缓存，暂停期间拒绝新读写；恢复先重新取得文件租约，失败继续保持暂停。
- 完全关闭仍不可恢复，暂停恢复不复用旧安全缓存。
- Engine 取消调用后保留真实在途登记，暂停等待其退出；操作门超时返回失败，之后可重试停止。
- TaskRegistry 和传输超时工作者取消后等待任务退出；资源未析构不能当作关闭完成。
- 取消传输失败后的重试仍执行取消，不因 session 已被取走而跳过。

## 2026-10-03 成员记录读取阻塞移动运行线程

- UniFFI 的密钥读取阻塞验收暴露了两个边界：零期限暂停返回只证明通知入队，不能立即放行密钥；成员维护的异步仓储入口直接执行同步事务，首次解密触发宿主密钥读取后会阻塞单线程运行期。
- `SqliteMembershipRecordStore` 在内部阻塞线程执行异步读取、提交与暂存的完整同步事务，沿用当前 tracing 上下文并保留任务失败来源。成员维护及生命周期负责人继续等待完整结果；不拆开事务，不改变重试、持久化格式或宿主接口。
- 公开契约统一阻塞该密钥的并发读取，防止后台维护抢走唯一阻塞机会；放行密钥前通过同一生命周期通道的查询确认暂停已转交 Engine，仍要求旧恢复返回 `InvalidState`，随后完整暂停、恢复、业务查询与并发关闭成功。临时调度延迟仅用于诊断，不进入产品实现。

## 2026-10-04 准入展示读取阻塞移动运行线程

- TestFlight 后台终止（`RUNNINGBOARD 0xdead10cc`）现场栈位于成员记录读取；同一设备分组查询链中，`SqliteSpaceAdmissionState`
  的当前加入与展示状态读取仍在异步入口直接执行同步读取与逐条解密。
- 两个读取入口改为在内部阻塞线程执行完整同步读取，沿用当前 tracing 上下文并保留任务失败来源；不拆开读取，不改变持久化格式、
  重试或宿主接口。仓储读取缓存随克隆共享。
- 机制级隔离实验（不是 Engine 生命周期端到端验证，未作为产品测试保留）：在与移动绑定同构的单线程运行期上，于读取闭包内注入
  延迟，修改前同一运行期上的对照任务被阻塞约 1.5 秒，修改后不再阻塞。
- 生命周期语义按源码核对：暂停先关闭入口并通知取消，再无期限等待在途操作实际退出，之后才释放资源并发布 Suspended；
  调用方期限只约束等待方。阻塞线程上的读取不可取消，暂停成功仍须等待它结束。本修复只避免读取期间整个运行线程冻结，
  不缩短暂停关键路径，也不保证宿主后台预算内完成。
- 真实双 Engine 场景未能在不增加生产测试钩子的前提下使该读取停住：解锁后准入密钥由内存恢复存储提供，不经宿主读取；
  资料库为 WAL，外部连接无法取得阻塞读取的锁。当前格式读取在逐条解密时不持有 SQLite 锁；旧格式迁移路径在即时事务内解密。
- 准入恢复（含周期恢复）、续接凭据、加入方与邀请方状态等其他异步入口仍在运行线程同步执行事务，需逐项核对后另行处理。
