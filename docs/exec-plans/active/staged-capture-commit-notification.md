状态：复现与修复中。

## 负责人和边界

Application 的剪贴板采集用例负责完整采集提交。Engine 调用方继续只提交完整采集动作，不增加产品侧步骤或查询接口。

暂存字节必须先持久化。记录与表示成功提交后，才能通知后台处理器。后台通知失败保留耐久暂存文件，由既有启动恢复扫描处理。提交失败不得发布后台任务；取消与进程退出仍依靠既有耐久暂存恢复，不增加持久化格式。

## 已复现的失败

先通过公开 Engine 的入站大图端到端场景复现，保持原图读取发生在缩略图就绪之后。再修正耐久暂存与后台通知顺序，验证缩略图、原图、锁定和重启既有场景。最后在固定远端 Engine 提交上重跑 Desktop 的真实 Linux 大视口场景，保持 50 条上限、解码与双向导航断言。未执行平台不得标为通过。
