# 移动 LAN 入站激活所有权

状态：实施中；基线 416fcca。

完整负责人是移动兼容层的 ApplyIncomingMobileClipUseCase。调用方只提交文档；共享入站管线负责存储和系统剪贴板写入，兼容层在成功后负责本地登记及状态传播。P2P 入站仍由共享入站管线登记发送者激活。

基线真实 Desktop daemon 的 LAN PUT→SSE→GET 验收中，新内容、A→B→A 与同内容再次激活都产生两次登记推进。共享管线先使用 mobile_sync 来源身份登记，兼容层随后使用本机身份和新时间登记。两个订阅者各收到两条，产生 19 次 GET，预期 11 次。

修复：入站请求明确选择登记负责人；共享登记辅助方法统一处理所有权。移动兼容层已装配本地激活公告时，由公告负责唯一登记；未装配时保留入站登记。已有内容的系统写入使用 RemotePush 自回声抑制，因为兼容层已经负责内容与状态的传播，不能再由 watcher 创建第二次激活。

成功：一次成功落地对应一次登记和通知；失败、取消、未完成文件不创建额外本地激活。重试与重启沿用既有入站和生命周期机制，不增加持久状态或协议字段。

验收：先有真实 daemon E2E 基线，再在同一 Desktop 来源下以隔离 Engine 覆盖构建，对比事件、GET 次数和精确文档匹配。覆盖两个订阅者、初始 hello、重连、连续不同内容及合法重复激活。系统剪贴板捕获、真机、文件和 lag/resync 未执行时明确记录跳过。
