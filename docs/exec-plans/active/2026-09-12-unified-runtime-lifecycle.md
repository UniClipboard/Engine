# 统一运行生命周期

状态：实施中。本切片只建立 Application 内部的统一负责人和行为合同，尚未接入具体业务、Engine 或移动宿主。

## 目标

- 暂停、恢复和最终关闭由一个完整负责人统一安排。
- 调用方只提交目标和共同期限，不读取内部阶段，也不拼接停止步骤。
- 会话工作、本地工作和本地资源使用同一转换上下文。
- 等待方离开不能遗弃已经接受的收尾。
- 失败必须保留原因，后续请求可以继续完成未结束的清理。

## 完整负责人

Application 的运行生命周期模块负责三类完整能力的先后关系：

1. 暂停时同时通知会话工作和本地工作停止。
2. 只有两类工作都安全结束后才释放本地资源。
3. 恢复时先准备本地资源，再恢复本地工作，最后恢复会话工作。
4. 恢复中途失败时按安全顺序清理已经启动的能力。
5. 最终关闭意图不可撤回，失败后只能继续收尾，不能再次恢复。

具体业务仍由所属模块完整负责。统一负责人不读取队列、任务、网络、存储或协议内部状态。

## 调用方动作与结果

- 调用方提交暂停、恢复或最终关闭请求。
- 成功表示所有要求的能力已经到达安全边界。
- 失败返回首要原因，并保留其余同时发生的失败。
- 请求被更新目标取代时，已经开始的完整能力仍执行到安全边界，再按最新目标收口。
- 等待者取消只结束等待，不取消负责人持有的实际收尾。

## 重试和重启责任

- 同一进程内未完成转换由本负责人保留状态并在下次请求前先清理。
- 各业务的持久恢复仍由各自业务负责人承担，不迁入通用生命周期模块。
- 进程终止后的未完成业务由后续 Stack 切片接入现有持久恢复依据。

## 分层计划

1. 建立统一负责人、固定三类能力和失败语义。
2. 分别让剪贴板、搜索、文件传输、成员维护和网络恢复拥有完整停止行为。
3. 让本地存储、安全材料和网络资源实现可重试的交接。
4. 由 Application 组装所属本地工作，Engine 只提供会话工作与本地资源。
5. 接入 Engine 启动、暂停、恢复、关闭和资料重置。
6. 接入移动绑定和专用验收宿主。
7. 完成真实重启、阻塞操作、设备矩阵和仓库门禁。

## 本切片验收

- 固定三类能力，不能通过参数位置混淆责任。
- 暂停与恢复顺序由测试证明。
- 同一转换共享代次和期限。
- 每个参与者调用都受共同期限约束，超时返回前终止对应调用任务。
- 重复目标不重复执行。
- 恢复失败会清理部分启动结果。
- 多项失败和任务异常不会丢失。
- 最终关闭失败后可以继续收尾，但永不重新开放。
- 调用方停止等待后，实际动作仍完成。

未接入的生产路径、平台和设备全部记为跳过，不把本模块测试表述为完整功能通过。

## 安全资源交接切片

- 资料密钥库把每次安全存储和文件访问作为自己持有的完整动作；调用方停止等待不会让访问失去负责人。
- 暂停先拒绝新访问并等待已开始的访问结束，再释放资料租约；恢复后重新读取外部变化。
- 活动 Space 切换先把完整目标材料放入不可见暂存区，全部安装成功后才一次发布。
- 切换失败、取消或并发清理不会暴露原控制库与目标安全材料混合的中间状态。
- 安全存储和文件失败保留原始原因，但公开错误和日志不包含密钥、路径或内容。
- 同步安全存储只由 Infra 的统一执行入口移交给阻塞线程；密钥材料与资料密钥库只提交完整动作，错误通过类型转换保留来源，调用处不再自行调度或映射。

验证范围：资料密钥库 20 项、活动 Space 安全会话 13 项、安全材料访问 2 项通过。生产 Engine 组装、移动宿主和实体设备仍为跳过。

## 网络节点清理切片

- 网络节点关闭由独立负责人持有，等待者离开或宿主期限到达都不会遗弃协议和路由清理。
- 所有协议清理会先收到通知；某一项失败不阻止其余资源释放，多个失败会完整保留。
- 路由任务已经异常退出时不会被误报为正常关闭。
- 观察连接在关闭过程中保持明确归属，不把未结束的网络任务当作已安全释放。

验证范围：网络关闭 4 项、生产节点连续重启 1 项通过。真实远端连接、移动系统后台和实体设备仍为跳过。
