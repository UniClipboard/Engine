# 规格 021 实施计划

## 目标

实现 `docs/specs/021-device-trust-reconciliation-product-contract.md` 中已获授权的完整查询、稳定决定、提醒、绑定与 DTR-01 至 DTR-11；恢复共同设备组因产品问题未确认，不实现 DTR-12。

## 完成标准

- [x] 完整查询一次返回来源、目标、两种选择影响和逐设备四维事实。
- [x] 决定支持首次完成、相同重复、相反重复、过期和本机退出二次确认。
- [x] 权威状态与最近决定加密持久化，重启后保持。
- [x] Engine 和三个平台入口语义一致，旧查询在同一交付中删除。
- [x] 提醒只要求重新读取完整结果，积压仍可恢复。
- [x] DTR-01 至 DTR-11 有接收端保存/应用或等价强证据；DTR-05 因缺少正式旧版程序与固定端口跳过。
- [x] 规格和架构记录同步，仓库强制检查通过；整套测试的既有配对失败已用未改基线确认。
- [x] 改动形成一个范围清晰的本地提交。
