# 设备组选择展示资料

## 完成标准

Engine 的选择查询提供已验证的候选成员及名称、选择后的同步范围/暂停/待确认、本机移除影响、语言无关原因事实。
资料随现有账本加密持久化，旧版本可读取并明确未知；不把预览当授权，不把未知当空组，不生成翻译文案。
产品转发保留新字段；单元、真实存储、真实 Engine、格式与仓库检查通过。现有修改和用户配置保留，不提交或发布。

## 阶段

- [x] 核对现有候选证据、查询和转发缺口。
- [x] Core 提供经过验证的原因事实；不返回自然语言文案。
- [x] Application 保存候选展示资料，并生成范围、暂停与待确认信息。
- [x] Infra 增加账本 V3 编码与 V2 升级，验证真实加密存储和重启。
- [x] Engine 丰富稳定查询输出，产品薄转发同步保留字段。
- [x] 完整测试、文档与交付门禁。

## 责任

ReconcileMembershipEvidenceUseCase 在验证来件后，同一提交保存冲突与展示资料。
ResolveMembershipConflictUseCase 查询可信候选并生成影响；既有选择/恢复负责人保持不变。
原因分类和关键变更由 Core 的历史规则提取；Infra 负责原加密存储能力，产品负责 i18n。

## 错误

五设备首轮恢复遇到连接超时；单独复测以及最终组合复测均通过，未放宽断言。
默认 Node 环境不支持现有前端测试依赖，使用 Node 24 验证通过，未修改依赖。
