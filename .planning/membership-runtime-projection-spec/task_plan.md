## Key Questions

1. 哪份状态唯一决定设备当前能否进入普通运行流程？
2. 哪些资料必须保留用于历史验证，哪些只是可重建缓存？
3. 跨多个存储写入中断时，如何保证重启后自动恢复一致？
4. 所有公开列表和后台任务如何共用同一资格判断，而不各自复制规则？

## Decisions Made

| Decision | Rationale |
|----------|-----------|
| `WorkspaceConvergence` 继续负责完整结果 | 符合 ADR-020 和现有分层，不新增并列负责人 |
| 本轮只写规格，不实施运行代码 | 用户要求先研究并撰写 spec |
| 不覆盖 `.planning/.active_plan` | 当前分支已有其他进行中的用户工作 |
| 普通运行资格立即关闭，历史通信资料按用途保留 | 移除决定仍需通知目标，历史验证也依赖旧身份；保留资料不得授予普通权限 |
| 清理失败不放宽资格，并由启动校正继续完成 | 安全正确性不能依赖多存储清理全部成功 |
