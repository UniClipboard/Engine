# Application Space 一次性重写规格计划

## Goal

基于当前生产入口、持久化格式、网络协议、用户可见结果和故障恢复行为，重建 `crates/uc-application/src/space` 的实际业务规格；以 `rebuild_space` 为用例结构参考，定义一次性替换旧成员关系及散落实现的目标结构、接口、流程、测试和删除清单。本阶段只产出规格，不继续迁移生产代码。

## Completion Criteria

- [x] 所有产品查询、用户命令、后台触发、网络入口和生命周期入口均有归属。
- [x] 所有成员历史、当前成员范围、授权、持久化、重试和恢复不变量均有代码或文档证据。
- [x] 每个目标用例写清唯一负责人、调用方唯一动作、输入、成功、失败及重启/重试归属。
- [x] 目标模块通过删除检查，不把内部步骤暴露给调用方。
- [x] Spec 给出一次性替换顺序及逐文件删除清单，不保留新旧双轨。
- [x] Spec 包含可判定的测试矩阵与验收条件。
- [x] 架构文档索引和维护记录同步更新。
- [x] 文档检查和 application 生产库检查通过；当前中间迁移导致的仓库级失败已明确记录。

## Phases

| Phase | Status | Description |
|---|---|---|
| 1. 建立入口与行为清单 | complete | 盘点产品、后台、网络、生命周期和组装入口 |
| 2. 重建状态与不变量 | complete | 追踪成员历史、授权、持久化、失败与恢复 |
| 3. 设计目标模块 | complete | 以 `rebuild_space` 为参考固定用例形状和内部职责 |
| 4. 编写一次性重写 Spec | complete | 固定对象、接口、流程、实施顺序和删除清单 |
| 5. 交叉核对与验证 | complete | 核对覆盖范围、更新架构文档并运行文档/仓库检查 |

## Decisions

- 当前工作树中的中间迁移只作为行为证据，不作为目标结构。
- 不在本任务中继续修改生产实现。
- 不设计渐进兼容层，不保留旧成员关系总对象和新结构并存。
- 外部稳定入口和已发布协议是否变化，必须从实际调用和文档证据决定，不能凭目录结构推断。
- 最终 Spec 只覆盖 application 层。Core、Infra、Engine、绑定、数据库和网络实现即使暂时不兼容，也不纳入本次设计或实施清单。

## Errors Encountered

| Error | Attempt | Resolution |
|---|---|---|
| `synchronize_membership_history/exchange.rs` 混入中文工作记录，当前树无法直接代表可编译基线 | 1 | 将其记录为中间改动污染；以 Git 基线、调用方和目标行为交叉核对，不在规格任务中修生产代码 |
| `cargo fmt --all -- --check` 失败 | 1 | 当前中间迁移已有大量未格式化 Rust 文件；本任务不修改生产代码，文档范围 `git diff --check` 单独通过 |
| 架构检查读取已移动的旧路径失败 | 1 | 当前脚本仍指向 `workspace_membership/projection/current_scope.rs`；application 实施前的中间状态问题，不在规格任务修复 |
| 全工作区 all-targets 编译失败 | 1 | 生产库编译已越过 application；测试目标因旧测试、旧 owner 和已改接口不一致出现 60 个错误，记录为当前中间迁移状态 |
